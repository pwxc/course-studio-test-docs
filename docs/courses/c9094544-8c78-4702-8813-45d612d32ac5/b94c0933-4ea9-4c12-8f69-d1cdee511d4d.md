# 第一章 · 训练数据

## 一条样本里，什么是输入？

例子：用房屋面积和室外气温预测当日电量。不看代码，先指出哪两列能在预测前拿到，哪一列是事后知道的答案。

| 样本 | 面积（㎡） | 气温（℃） | 日电量（kWh） |
| -- | ----- | ----- | -------- |
| 01 | 72    | 30    | 11.2     |
| 02 | 85    | 33    | 14.8     |
| 03 | 60    | 26    | 7.4      |

样本编号只用于追踪。面积和气温是特征，电量是标签。把两列特征组成 X，把一列标签组成 y。

$$
X_{1,:} = [72, 30], \quad y_1 = 11.2
$$

## 谁可以看答案？

![10 条样本分成 6 条训练、2 条验证、2 条测试](/assets/d8f2e951-aec4-4a98-809b-dff64ddd55b7.png)

训练集用来学参数，验证集用来选模型，测试集等方案定好后再做最终评估。

这里的样本是虚构的，6:2:2 只为演示。真实数据如果来自同一栋房子或连续日期，常需要按房屋或时间划分，而不是把所有行随机打散。

## 动手：给 10 条样本分组

```python
from random import Random

rows = list(range(1, 11))
Random(21).shuffle(rows)
train, valid, test = rows[:6], rows[6:8], rows[8:]
print(train, valid, test)
```

## 识别数据泄漏

### 两个看起来很准的模型

模型 A 只拿面积和气温；模型 B 还拿了当天结束后才产生的电费账单。即使 B 的分数更好，也不能据此说它适合预测当日电量。

### 划分之后，才算标准化参数

只在训练集计算均值和标准差；验证集和测试集使用训练集算出的同一组参数，不重新拟合。

$$
z = \frac{x - \mu_{\mathrm{train}}}{\sigma_{\mathrm{train}}}
$$
